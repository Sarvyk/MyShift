# MyShift — Telegram-бот планировщик смен

## Обзор проекта

**MyShift** — это Telegram-бот для управления сменными графиками. Бот позволяет:
- Регистрировать пользователей в системе
- Создавать шаблоны графиков с указанием времени и дней работы
- Генерировать графики для конкретных пользователей на основе шаблонов
- Подавать заявки на смену расписания
- Управлять заявками (просмотр, удаление)

### Архитектура

Проект построен на **.NET 8** и использует следующую структуру:

```
MyShift/
├── Program.cs              — Точка входа, инициализация бота
├── UpdateHandler.cs        — Обработка обновлений от Telegram (команды, диалоги)
├── Core/
│   ├── Data/               — DbContext для SQLite (SqLiteDbContext)
│   ├── Entities/           — EF-модели (ToDoUser, Request, Schedule, ScheduleTemplate, CycleShift)
│   ├── Enums/              — Перечисления (Role, RequestStatus, Weekday)
│   ├── Interfaces/         — Интерфейсы сервисов и репозиториев
│   ├── Services/           — Бизнес-логика (UserService, ScheduleRequestService, ScheduleBuilder)
│   ├── Dialogs/            — Интерактивные диалоги для пошагового ввода данных
│   ├── Extensions/         — Методы-расширения
│   └── Helpers/            — Вспомогательные утилиты
├── Repositories/           — Репозитории для работы с БД (UserRepository, RequestRepository, ScheduleRepository)
```

### Сущности базы данных

- **ToDoUser** — пользователь бота (chatId, telegramId, имя, роль)
- **Request** — заявка на изменение расписания (статус: Pending/Approved/Rejected)
- **Schedule** — конкретный график смены для пользователя
- **ScheduleTemplate** — шаблон графика (имя, время начала/окончания, дни недели)
- **CycleShift** — циклическая смена в рамках графика

### Роли пользователей

- **Administrator** — полный доступ (создание шаблонов, графиков, обработка заявок)
- **Moderator** — частично расширенный доступ
- **User** — базовый доступ (просмотр графика, подача заявок)

### Роутинг команд

| Команда | Описание |
|---|---|
| `/start` | Регистрация/приветствие |
| `/help` | Список доступных команд |
| `/создать шаблон` | Пошаговый диалог создания шаблона графика |
| `/создать график` | Пошаговый диалог создания графика для пользователя |
| `/график` | Показать текущий график |
| `/добавить заявку [описание]` | Создать заявку на смену расписания |
| `/заявки` | Показать список заявок |
| `/удалить заявку [номер]` | Удалить заявку по номеру |

## Технологии

- **.NET 8** (C#)
- **Telegram.Bot** — библиотека для работы с Telegram Bot API
- **Entity Framework Core + SQLite** — ORM и база данных
- **DotNetEnv** — загрузка переменных окружения из `.env` файла

## Запуск и разработка

### Предварительные требования

- .NET 8 SDK
- Файл `.env` с переменной `API_TOKEN` (токен Telegram-бота)

### Запуск

```bash
dotnet run --project MyShift/MyShift.csproj
```

### Сборка

```bash
dotnet build MyShift.slnx
```

### Публикация

```bash
dotnet publish MyShift/MyShift.csproj -c Release
```

### Настройка окружения

Создайте файл `.env` в корневой директории проекта:

```
API_TOKEN=your_telegram_bot_token_here
```

## Примечания

- База данных SQLite создаётся автоматически (`mydb.db`) при запуске.
- В `SqLiteDbContext` присутствует `Database.EnsureDeleted()` — **это удаляет и пересоздаёт БД при каждом запуске**. Для продакшена это следует убрать.
- Обработка ошибок в `UpdateHandler` пока минимальна — вывод в консоль.
- Некоторые команды (например, `/график`) имеют заглушку и не реализованы полностью.
- Пошаговые диалоги реализованы через интерфейс `IDialog` и словарь `_waitMessage`.
